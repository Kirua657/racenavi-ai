# PRD — RaceNavi AI

## Product name

RaceNavi AI

## One-line description

AIが「予想」だけでなく「買い方」までサポートする競馬アプリ。

## Problem

競馬初心者は、予想サイトや競馬新聞の情報量・専門用語に圧倒されやすい。  
多くのサービスは「何を買うか」は示すが、初心者が本当に迷う「どう買えばよいか」までは一貫して支援しきれていない。

## Target users

### Main target

SNS、YouTube、GⅠレースをきっかけに競馬へ興味を持った20〜30代の初心者。  
競馬新聞や専門サイトの情報量に圧倒され、「どの馬を買うか」よりも「どう買えばよいか」で迷っている。  
少額予算で楽しみたいが、トリガミや無駄な買い方を避けたいニーズを持つ。

### Secondary target

- 予想はできるが買い方の最適化が苦手な中級者
- 自分の買い方を振り返りたいユーザー

## Value proposition

RaceNavi AIは「当てることを保証するアプリ」ではない。  
初心者が少額で納得感を持って競馬を楽しみ、結果を振り返りながら学べる体験を提供する。

## Core user flow

1. レースを選ぶ
2. AI予想を見る
3. なぜその馬なのかを読む
4. 予算と好みを入力する
5. 買い目・金額配分を見る
6. 提案買い目を保存する
7. レース結果と照合して振り返る

## MVP success metrics

- 買い目提案利用率
- 買い目保存率
- 購入後振り返り率
- 4週間継続利用率
- App Store/ユーザーフィードバック評価

Do not use "profit improvement" as the primary success metric.
