# UX Flow

## Page 1: Landing

Goal:
- Explain concept quickly.
- CTA to race list.

Copy:
- "予想だけでなく、買い方までサポート"
- "初心者が少額で納得して楽しむための競馬アプリ"

## Page 2: Race List

Cards:
- Race name
- Venue/race number
- Course/distance
- Start time
- Going
- CTA: "予想を見る"

## Page 3: Race Detail

Sections:
1. Race summary
2. Entries table
3. Prediction marks
4. Beginner explanation
5. Bet plan generator
6. Disclaimer

## Page 4: Bet plan result

Display:
- Total budget
- Suggested tickets
- Stake
- Rationale
- Save button
- Disclaimer

## Page 5: History

Display:
- Saved plans
- Stake/payout/profit
- ROI summary
- Manual result input
