# RaceNavi AI MVP デモシナリオ

この資料は、RaceNavi AI MVPを友達・先生・関係者に見せるときの操作順をまとめたものです。説明では「予想支援」「買い目シミュレーション」「振り返り」の流れが伝わるようにします。

## 1. 事前準備

Backend と Frontend を起動します。

```powershell
cd C:\dev\keibaapp\backend
.\.venv\Scripts\activate
python -m uvicorn app.main:app --reload
```

```powershell
cd C:\dev\keibaapp\frontend
npm run dev
```

ブラウザで次を開きます。

```text
http://localhost:3000/races
```

## 2. レース一覧を見せる

URL:

```text
http://localhost:3000/races
```

見せるポイント:

- 東京11R 日本ダービー、東京12R 目黒記念、京都11R 葵ステークスが並ぶこと
- 開催日、競馬場、芝/ダート、距離、レース名で絞り込めること
- CSVを差し替えると、レース一覧も差し替わること

説明例:

> ここでは、手元で用意したCSVのレースデータを一覧で確認できます。開催日や競馬場、距離で絞り込めるので、デモでは複数レースの中から見たいレースを選べます。

## 3. レース詳細を見せる

おすすめURL:

```text
http://localhost:3000/races/tokyo-2026-05-31-11
```

見せるポイント:

- 出馬表に馬番、人気、オッズ、脚質が表示されること
- AI予想カードで本命、対抗、穴馬、危険人気馬が分かること
- 評価ポイントが初心者向けの言葉で表示されること
- 「スコア内訳を開く」で、どの条件が何点加点されたか見えること

説明例:

> 日本ダービーは東京芝2400mなので、差し・追込、距離適性、東京コース適性を評価しています。印だけではなく、なぜ評価したかをカードで確認できます。

## 4. 予算3000円で買い目生成を見せる

レース詳細画面の下にある「買い目生成」を使います。

入力例:

```text
予算: 3000円
目的: バランス
リスク: 中
3連単を含める: オフ
```

操作:

1. 予算に `3000` を入力します
2. 目的は `バランス` を選びます
3. リスクは `中` を選びます
4. `買い目を作る` を押します
5. 券種、組み合わせ、金額、合計金額、提案理由を確認します
6. `履歴で確認する` を押します

説明例:

> 予算と目的に合わせて、買い目の候補を自動で組みます。これは購入指示ではなく、予想をどう買い目に落とし込むかを考えるためのシミュレーションです。

## 5. 履歴と結果入力を見せる

URL:

```text
http://localhost:3000/history
```

見せるポイント:

- 保存された買い目が履歴カードで見えること
- 合計購入額、払戻額、収支、回収率、的中率が上部にまとまること
- 結果入力フォームで、払戻、的中、1〜3着、本命着順、メモを入力できること
- 結果入力後、AI予想の振り返り文が表示されること

入力例:

```text
的中: 任意
払戻額: 1200
1着: 12
2着: 5
3着: 3
本命の着順: 1
メモ: 本命は評価通り。相手候補の拾い方を次回確認。
```

説明例:

> 買い目を保存して終わりではなく、結果を入れて振り返れるのがポイントです。回収率や的中率は過去の記録として表示し、次の改善材料にします。

## 6. CSV取り込みを見せる

URL:

```text
http://localhost:3000/admin/import
```

見せるポイント:

- CSVファイルを選んでアップロードできること
- 成功時に取り込んだレース数、出走馬数が出ること
- CSVに問題がある場合、行番号と項目名が分かること
- 外部サイトからの直接スクレイピングではなく、手元CSVから取り込む設計であること

説明例:

> 今は外部サイトから自動取得するのではなく、合法的に用意したCSVだけを取り込みます。CSVを差し替えれば、デモ用レースや検証用レースを簡単に入れ替えられます。

## 7. 注意点

- RaceNavi AI MVPは、的中や利益を保証しません
- 表示される予想、買い目、回収率は参考情報です
- 馬券購入は利用者自身の判断と責任で行います
- CSVは、合法的に利用できるデータのみを使います
- netkeibaなど外部サイトからの直接スクレイピングは実装しません
- 外部データを使う場合は、利用規約、著作権、データベース権を確認します

## 8. デモのおすすめ順

1. `/races` で複数レースを見せる
2. 日本ダービーの詳細を開く
3. AI予想カードとスコア内訳を見せる
4. 予算3000円で買い目生成する
5. `/history` で保存された買い目を見せる
6. 結果入力をして振り返り文を見せる
7. `/admin/import` でCSV取り込みの仕組みを説明する

この順番だと、「データを入れる」「予想を見る」「買い目にする」「結果を振り返る」というMVP全体の価値が伝わりやすくなります。
