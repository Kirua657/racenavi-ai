# RaceNavi AI MVP デモシナリオ

この資料は、RaceNavi AI MVPを友達・先生・関係者に見せるときの操作順をまとめたものです。説明では「予想支援」「買い目シミュレーション」「任意の振り返り」の流れが伝わるようにします。

## 1. 事前準備

Backend と Frontend を起動します。

```powershell
cd C:\dev\keibaapp\backend
.\.venv\Scripts\activate
python -m uvicorn app.main:app --reload
```

```powershell
cd C:\dev\keibaapp\frontend
npm run dev
```

ブラウザで次を開きます。

```text
http://localhost:3000/races
```

## 2. レース一覧を見せる

URL:

```text
http://localhost:3000/races
```

見せるポイント:

- 東京11R 日本ダービー、東京12R 目黒記念、京都11R 葵ステークスが並ぶこと
- 開催日、競馬場、芝/ダート、距離、レース名で絞り込めること
- レースカードからAI予想と買い目プランへ進めること
- CSVを差し替えると、レース一覧も差し替わること

説明例:

> ここでは、手元で用意したCSVのレースデータを一覧で確認できます。まずレースを選び、詳細画面でAI予想と買い目シミュレーションを見ます。

## 3. レース詳細を見せる

おすすめURL:

```text
http://localhost:3000/races/tokyo-2026-05-31-11
```

見せるポイント:

- 出馬表に馬番、人気、オッズ、脚質が表示されること
- AI予想カードで本命、対抗、穴馬、危険人気馬が分かること
- 評価ポイントが初心者向けの言葉で表示されること
- 「スコア内訳を開く」で、どの条件が何点加点されたか見えること

説明例:

> 日本ダービーは東京芝2400mなので、差し・追込、距離適性、東京コース適性を評価しています。印だけではなく、なぜ評価したかをカードで確認できます。

## 4. 予算3000円で買い目シミュレーションを見せる

レース詳細画面の下にある「買い目シミュレーション」を使います。

入力例:

```text
予算: 3000円
目的: バランス
リスク: 中
3連単を含める: オフ
```

操作:

1. 予算に `3000` を入力します
2. 目的は `バランス` を選びます
3. リスクは `中` を選びます
4. `買い目プランを作る` を押します
5. 確認画面で券種、組み合わせ、合計想定額、提案理由を確認します
6. `この予想メモを保存` を押します
7. `保存した予想` 画面へ移動したことを確認します

説明例:

> 予算と目的に合わせて、買い目の候補を自動で組みます。これは購入指示ではなく、AI予想をどう買い目に落とし込むかを考えるためのシミュレーションです。このアプリ上で馬券購入や投票は行いません。

## 5. 保存した予想と任意の振り返りを見せる

URL:

```text
http://localhost:3000/history
```

見せるポイント:

- ここは購入履歴ではなく、保存した予想メモの一覧であること
- 保存した想定額、振り返り済み想定額、仮想回収率が表示されること
- 未振り返りの予想は、仮想収支や仮想回収率に混ぜないこと
- レース後の振り返りフォームは任意で、最初は折りたたまれていること
- 振り返り入力後、AI予想の振り返り文が詳しくなること

任意入力例:

```text
買い目シミュレーションが的中: 任意
仮の払戻額: 1200
1着: 12
2着: 5
3着: 3
本命の着順: 1
メモ: 本命は評価通り。相手候補の拾い方を次回確認。
```

説明例:

> 保存して終わりではなく、レース後に任意で振り返れるのがポイントです。仮想回収率や的中率は、入力した振り返り記録だけから計算します。

## 6. CSV取り込みを見せる

URL:

```text
http://localhost:3000/admin/import
```

見せるポイント:

- CSVファイルを選んでアップロードできること
- 成功時に取り込んだレース数、出走馬数が出ること
- CSVに問題がある場合、行番号と項目名が分かること
- 外部サイトからの直接スクレイピングではなく、手元CSVから取り込む設計であること

説明例:

> 今は外部サイトから自動取得するのではなく、合法的に用意したCSVだけを取り込みます。CSVを差し替えれば、デモ用レースや検証用レースを簡単に入れ替えられます。

## 7. 注意点

- RaceNavi AI MVPは、的中や利益を保証しません
- 表示される予想、買い目、仮想回収率は参考情報です
- このアプリ上では馬券購入・投票・購入代行を行いません
- 馬券購入を行う場合は、利用者自身の判断と責任で行います
- CSVは、合法的に利用できるデータのみを使います
- netkeibaなど外部サイトからの直接スクレイピングは実装しません
- 外部データを使う場合は、利用規約、著作権、データベース権を確認します

## 8. デモのおすすめ順

1. `/races` で複数レースを見せる
2. 日本ダービーの詳細を開く
3. AI予想カードとスコア内訳を見せる
4. 予算3000円で買い目シミュレーションを作る
5. 確認画面で「購入ではなく保存する予想メモ」であることを説明する
6. `保存した予想` で保存された予想メモを見せる
7. 任意のレース後振り返りを開き、入力すると分析が詳しくなることを見せる
8. `/admin/import` でCSV取り込みの仕組みを説明する

この順番だと、「データを入れる」「予想を見る」「買い目にする」「保存する」「振り返る」というMVP全体の価値が伝わりやすくなります。
