# RaceNavi AI 発表用メモ

## 1. なぜ作ったか

競馬初心者にとって、予想印だけを見ても「なぜその馬なのか」「どう買い目にすればいいのか」「あとで何を振り返ればいいのか」が分かりにくい。RaceNavi AI は、予想の理由、買い目シミュレーション、結果の振り返りを1つの流れにまとめるためのMVPとして作った。

## 2. 何ができるか

- 複数レースを一覧で確認できる
- 開催日、競馬場、芝/ダート、距離、レース名で絞り込める
- レース詳細で出馬表とAI予想を見られる
- 本命、対抗、穴馬、危険人気馬をカードで確認できる
- 評価ポイントとスコア内訳で、なぜ評価されたかを見られる
- 予算3000円など、予算に合わせて買い目を生成できる
- 買い目を履歴に保存できる
- 結果入力後、損益サマリーとAI予想の振り返りを確認できる
- CSVからレースデータを取り込める

## 3. 何をやらないか

- 実際の馬券購入はしない
- 自動投票、購入代行、決済機能は作らない
- 的中や利益を保証しない
- 外部サイトから直接スクレイピングしない
- 法的権利が不明なデータを自動収集しない

## 4. デモで見せる順番

1. `/races` で複数レースとフィルターを見せる
2. 東京11R 日本ダービーを開く
3. 出馬表、AI予想カード、評価ポイントを見せる
4. スコア内訳を開き、条件別の加点を説明する
5. 予算3000円、目的バランス、リスク中で買い目生成する
6. `/history` に移動し、保存された買い目を見せる
7. 結果入力を行い、損益サマリーとAI振り返りを見せる
8. `/admin/import` でCSV取り込み画面を説明する

## 5. 今後の改善

- 実データを安全に扱うためのデータ取得・利用ルールを整理する
- レース条件ごとのスコア補正を増やす
- 的中、不的中の振り返り分析を詳しくする
- 買い目生成の選択肢を増やす
- UIをさらにスマホ向けに調整する
- GitHub Actionsの結果をREADMEで確認できるようにする

## 6. 注意して伝えること

RaceNavi AI は予想や買い目を考えるための参考ツールであり、的中や利益を保証するものではない。CSVに入れるデータは、手元で合法的に利用できるものだけを使う。
